How to Search

Our search engine allows you to find entries in the Cyclic Peptide DataBank using various criteria. You can perform a general keyword search or use specific identifiers.

  • PDB IDs: Enter a 4-character PDB identifier (e.g., 1CRN) to go directly to that entry.
  • Keywords: Search for protein names (e.g., insulin), organism names (e.g., human), or experimental methods (e.g., X-RAY DIFFRACTION).
  • Sequences: You can search for peptides by their amino acid sequence. The search will return entries containing that sequence.
  • UniProt Numbers: Use UniProt accession numbers to find associated structures.

The search results will be displayed on this page once a search is performed. You can then click on any entry to view its detailed information and 3D structure.
